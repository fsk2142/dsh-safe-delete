# 安全删除

删除先进安全区，保留期内可原样取回；到期后自动移入系统回收站。

## 删除

| 方式 | 用法 |
|---|---|
| 让模型删 | 直接说「删掉 xxx」，或在调用里传 `path` / `paths` / `root` + `match` |
| 对话里删 | `/safe-delete <路径>` |
| 终端里删 | `dsh-safe-delete delete <路径>` |

删之前想先看一眼会删掉什么：`/safe-delete <路径> --preview`。

## 取回

| 方式 | 用法 |
|---|---|
| 看有哪些 | `/safe-delete list` |
| 按条目取回 | `/safe-delete restore <id>` |
| 从回收站取回 | 资源管理器里「还原」 |

## 设置

| 项 | 说明 |
|---|---|
| 删除去向 | `放入安全区`：可在插件内取回。`直接进回收站`：更快，取回要用资源管理器 |
| 安全区保留天数 | 到期后自动移入系统回收站，至少 1 天 |
| 单次删除条目数确认 | 超过这个数量先问一次，`0` 关闭 |
| 单次删除大小确认 | 超过这个大小先问一次，`0` 关闭 |

改完配置需重启 DSH 生效；**删除去向按钮例外**，点一下立即生效。

## 遇到提示

| 提示 | 意思 |
|---|---|
| 弹出审批卡片 | 路径危险或这次删得多。点「允许一次」才会执行 |
| 直接拒绝，没弹卡 | 审批策略是 `never`，而这次删除无法证明可恢复 |
| 安全区里找不到刚删的 | 删除去向设成了「直接进回收站」 |
| 提示改用 `safe_delete` | 裸 shell 删除被拦下了 |
