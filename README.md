# dsh-safe-delete

DSH 删除的撤销层：删除先进安全区，到期移入系统回收站，清空回收站才真正消失。

## 怎么删

| 方式 | 用法 |
|---|---|
| 让模型删 | 直接说「删掉 xxx」 |
| 在对话里删 | `/safe-delete <路径>` |
| 在终端里删 | `dsh-safe-delete delete <路径>` |

删之前想先看一眼会删掉什么：`/safe-delete <路径> --preview`。

## 怎么取回

| 方式 | 用法 |
|---|---|
| 看有哪些 | `/safe-delete list` |
| 按条目取回 | `/safe-delete restore <id>` |
| 从回收站取回 | 资源管理器里「还原」 |

## 遇到这些提示是什么意思

| 提示 | 意思 |
|---|---|
| 弹出审批卡片 | 路径危险，或这次删得太多。点「允许一次」才会执行 |
| 直接拒绝，没弹卡 | 审批策略是 `never`，而这次删除无法证明可恢复 |
| 安全区里找不到刚删的 | 删除去向设成了「直接进回收站」，取回要用资源管理器 |
| 提示改用 `safe_delete` | 裸 shell 删除被拦下了，换成上面三种方式之一 |
