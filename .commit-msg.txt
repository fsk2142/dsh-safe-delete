Removes scripts that existed only for this one development cycle, whose
value is now fully carried by the test suite:

- probe-classification.ts / audit-coverage.ts / probe-form-units.ts

  location, which works on any machine.
- tests/classify.test.ts and the plan document carried `<workspace>` in
  path literals where a normal directory name belongs.
